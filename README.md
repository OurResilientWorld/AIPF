# AI Product Flow

Practical guides and case studies for decisions about AI products, product families and portfolios.

[Explore the website](https://aipf.ourresilient.world/index.html).

## Edition 1.0

Five guides: Framework, Product, Product Family, Portfolio and Portfolio Implementation.

Six case studies: HarbourBridge; Project Lantern; AI-Assisted Research; Portfolio Dashboard MVP; AI Motion Story System; Commonwealth Budget Explorer. Each case explains its evidence and limitations.
