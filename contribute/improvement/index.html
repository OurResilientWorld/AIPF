Proposal details

Tell us what needs improving and why. You do not need to propose a solution or design a test. The other text fields are optional. Issues are public; do not include confidential, sensitive or personal information. Submission does not imply endorsement, funding or acceptance.

Describe what is unclear, missing or difficult, and how it affects you.

Optional. Add a page link or heading if you know it; leave blank for a general suggestion.

Confirm the public submission acknowledgement on GitHub after reviewing your answers.

Review and submit on GitHub

The review link carries your answers to GitHub in its URL. GitHub may require sign-in. Check every answer there and confirm the public submission acknowledgement before submitting. Your original text stays in this tab.

Alternative route

If JavaScript is unavailable, or your answers do not transfer, use the GitHub form directly. For a long proposal, download your draft and paste each answer into its matching field.

Open GitHub form directly

GitHub issues and comments are public. Do not include confidential, sensitive or personal information. A GitHub account is required to submit.

What happens next?

Maintainers classify the issue, review it and may ask for clarification. Submission does not automatically change a guide, accept evidence or commit to an improvement. Accepted changes are prepared privately and released after review and Product Owner approval. No response time is promised.
